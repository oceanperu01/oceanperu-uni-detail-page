# 상세페이지 통일 레이아웃 v2

모든 상세페이지가 같은 7칸 순서를 따르도록 만든 와이어프레임입니다. v2에서는 후기를 빼고, 문구를 줄이는 대신 이미지 자리를 늘렸습니다.
사진과 세부 문구는 비워 두었습니다(빗금 = 사진 자리, 회색 바 = 문구 자리). 파란 빗금에 "생성형 가능"이 붙은 칸은 생성형 이미지로 채워도 되는 자리이고, 회색 빗금은 실제 제품 사진이 필요한 자리입니다.
`index.html`을 브라우저로 열면 위쪽 검토용 패널에서 상품 수(1~4), 보관 방식(냉동·냉장·상온), 선택 섹션을 바꿔 볼 수 있습니다. 패널과 검은 번호표는 실제 페이지에 넣지 않습니다.

| 순서 | 섹션 | 구분 | 상품 수에 따른 변화 |
|---|---|---|---|
| ① | 히어로 (대표 사진 + 제품명 + 한 줄 카피 + 신뢰 배지 3개) | 필수 | 없음 |
| ② | 핵심 스펙 3칸 (원산지 · 구성 · 활용) | 필수 | 구성 칸이 "N종 구성" |
| 띠 | 이미지 띠 A (원산지·바다 풍경) | 필수 | 없음 |
| ③ | 구성·규격 카드 | 필수 | 1개 = 가로 카드, 2~4개 = 그리드 + 첫 카드에 "많이 찾는" 리본, 카드마다 "이런 분께" 한 줄 |
| ④ | 활용법 이미지 3장 | 필수 | 없음 |
| ⑤ | 제품 포인트 이미지 카드 3개 | 선택 | 없음 |
| 띠 | 이미지 띠 B (식탁 장면) | 필수 | 없음 |
| ⑥ | 보관·배송 (가공 단계 선택 + 포장) | 공통 블록 | 보관 방식에 따라 포장 문구 자동 |
| ⑦ | FAQ 3개 + 상품 정보 고시 | 필수 | 품목별 값 줄 추가 |

- 섹션 번호(Q1, Q2…)는 쓰지 않습니다.
- 한 페이지에 여러 상품이 있어도, 같은 상품을 개별로 올려도 ③과 ⑦만 달라지고 나머지는 동일합니다.
- 신뢰 배지 문구(예: 직수입, 납품처, 배송 일수)는 사실 확인 후 채웁니다.
- 최대 폭 860px, 모바일 375px 기준으로 설계했습니다.
