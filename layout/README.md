# 상세페이지 기본 레이아웃 (우니 기반 모듈형)

운영 중인 우니 상세페이지(detail.oceanperu.co.kr)의 디자인을 그대로 쓰고, 섹션을 모듈로 나눠 제품마다 필요한 모듈만 켜는 방식입니다.
가격, 푸터, 전체 상품·구매 안내, 전화 문의, 분석 태그는 넣지 않습니다. 운영 페이지(저장소 루트 `index.html`)는 바꾸지 않습니다.

| 순서 | 모듈 | 구분 | 비고 |
|---|---|---|---|
| ① | 히어로 (문구 + 대표 이미지 + 완제품 원형 사진) | 필수 | 거리 숫자·유통 경로는 선택 |
| ② | 핵심 3칸 | 필수 | |
| ③ | 사진 확인 갤러리 + 포인트 3개 | 선택 | 부위 비교 등에도 사용 |
| ④ | 활용 카드 1~3장 | 필수 | |
| ⑤ | 구성·규격 | 필수 | 상품 1개 = 규격표, 여러 개 = 라인업 카드 |
| ⑥ | 공정 2~4단계 | 선택 | |
| ⑦ | 유통 구조 (WHY DIRECT) | 선택 | 직수입 제품만 |
| ⑧ | 보관·해동 | 필수 | 메뉴얼 링크 또는 안내 문구 |
| ⑨ | 정보 고시 | 필수 | 여러 상품이면 품목별 줄바꿈 |

## 파일

- `build.py`: 생성기. 루트 `index.html`의 CSS·스크립트를 가져와 `PRODUCTS` 내용으로 페이지를 만듭니다. 저장소 루트에서 `python3 layout/build.py` 실행.
- `index.html`: 우니 (전체형, 모든 모듈)
- `preview-tuna.html`: 참다랑어 (축약형, 기존 Figma 상세페이지 내용 결합)
- `preview-ginger.html`: 초생강 3종 (최소형, 한 페이지 여러 상품)
- `img/`: 참다랑어 이미지 (Figma v1 상세페이지에서 가져옴)
- `wireframe-v2.html`: 이전 와이어프레임 (참고용)

미리보기의 번호표(검정 필수·갈색 선택), 노란 점선(확인 필요 문구), 빗금(사진 자리)은 검토용이며 위쪽 바의 버튼으로 끌 수 있습니다.
